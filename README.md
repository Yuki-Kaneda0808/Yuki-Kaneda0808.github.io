# Yuki Kaneda — personal research website

A lightweight static website designed for GitHub Pages.

## Files
- `index.html` — Home
- `research.html` — Research vision
- `works.html` — Selected publications
- `styles.css` — Shared styling

## Publish on GitHub Pages
For the repository `Yuki-Kaneda0808.github.io`, place these files in the repository root on the `main` branch.
GitHub Pages should then serve the site at:

https://yuki-kaneda0808.github.io

If Pages is not active, open the repository on GitHub and go to:
Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`.

## Edit later
The site has no build step or framework. You can edit the HTML and CSS directly.

The profile image currently uses the GitHub avatar URL. Replace the `<img src="...">` in `index.html`
with a local image such as `assets/profile.jpg` if you prefer.
